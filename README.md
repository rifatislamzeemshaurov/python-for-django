## 🚀 How to Start

**1. Install Python** from [python.org](https://www.python.org/downloads/).
⚠️ On Windows, tick **"Add Python to PATH"** during installation!

**2. Download this course**
```bash
git clone https://github.com/rifatislamzeemshaurov/python-for-django.git
cd python-for-django
```
(Or click the green **Code → Download ZIP** button on GitHub.)

**3. Create a virtual environment and install Jupyter**
```bash
python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # Mac / Linux

pip install -r requirements.txt
```

**4. Open the notebooks**
```bash
jupyter notebook
```
Then open **`00-Welcome-and-Setup/00-Welcome.ipynb`** and have fun! 🎉

> 💡 **No installation?** Upload any notebook to [Google Colab](https://colab.research.google.com/) and learn right in your browser.
> You can also open the notebooks in **VS Code** with the *Python* and *Jupyter* extensions.

## 🌟 Tips for Students

1. **Type the code yourself.** Don't just copy and paste.
2. **Break things on purpose.** Errors teach you a lot!
3. **Try every exercise** before opening the solution.
4. **A little every day** beats a lot once a week.
5. **Stuck?** Re-read the lesson, then ask. Asking questions is a superpower. 💪
